# Teaching Polls

Classroom polling site connected to the deployed Supabase backend.

## Publish

1. Open this repository in GitHub Desktop and select **Publish repository**. Use a public repository for free GitHub Pages hosting.
2. On GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**, and save.
3. Open the published site followed by `/admin.html` to create a poll.
4. Bookmark the private presenter address. Share only the voting link or QR code.

The browser configuration contains a public publishable key. Server secrets are not included.
The full backend source and tests remain on the T7 in `Teaching Demo/Teaching Polls/`.
